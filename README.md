# heimdash

Single-binary NixOS home-server dashboard.

- Zig stdlib backend.
- Datastar SSE patches.
- Embedded HTML/CSS/JS assets.
- JSON config generated by the NixOS module.

## Commands

```sh
nix develop
zig build
zig build run -- --config /path/to/config.json
nix flake check
nix build .#default
nix fmt
```

No local Nix requirement in this workspace. CI is the canonical Nix check.

## NixOS Module

```nix
{
  inputs.heimdash.url = "github:reuski/heimdash";

  outputs = { nixpkgs, heimdash, ... }: {
    nixosConfigurations.server = nixpkgs.lib.nixosSystem {
      modules = [
        heimdash.nixosModules.default
        {
          services.heimdash = {
            enable = true;
            listen = "127.0.0.1:8080";
            mounts = [ "/" "/srv/media" ];
            services = [
              { name = "AdGuard"; url = "http://adguard.example.invalid"; }
              { name = "Jellyfin"; url = "http://jellyfin.example.invalid"; }
              { name = "Sonarr"; url = "http://sonarr.example.invalid"; }
              { name = "Radarr"; url = "http://radarr.example.invalid"; }
              { name = "Prowlarr"; url = "http://prowlarr.example.invalid"; }
              { name = "qBittorrent"; url = "http://qbittorrent.example.invalid"; }
              { name = "Home Assistant"; url = "http://home-assistant.example.invalid"; }
            ];
          };
        }
      ];
    };
  };
}
```

## Routes

| Method | Path           | Response          |
| ------ | -------------- | ----------------- |
| `GET`  | `/`            | HTML              |
| `GET`  | `/poll`        | metrics SSE patch |
| `GET`  | `/style.css`   | embedded CSS      |
| `GET`  | `/datastar.js` | embedded JS       |
